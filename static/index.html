Tweensy

Set up this computer

Tweensy uses Claude Code with your own Claude plan (Pro or Max). Do the steps that aren't ticked yet, then press Check again.

    Storyboard

    Black pen: what's on screen. Red arrows: how things move (write 1, 2, 3 for the order). Blue text: labels.

    Add files to this project

    Pick where your files go, or drag them onto a card. Claude can then use them in your video.
